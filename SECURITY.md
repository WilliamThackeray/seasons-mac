# Security and privacy

Snowy reads public window bounds and pointer position to place snow. The optional **Allow Icon Anchors** action requests macOS Accessibility permission for Finder icon geometry. Snowy uses icon bounds and local hashes of Finder identifiers to track those anchors. Imported wallpapers, scenes, and preferences stay on your Mac. The updater checks GitHub for signed releases.

Please don’t put credentials or unrelated private desktop contents in a public report. If you find a security issue, use GitHub’s **Report a vulnerability** option when available. Otherwise, open an issue asking for a private contact without posting exploit details or sensitive data.

Release DMGs and ZIPs include SHA-256 checksums. Sparkle verifies the update feed and archive before installation. Current beta releases use local code signing and may require first-launch approval in System Settings.
